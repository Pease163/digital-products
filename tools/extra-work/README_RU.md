# Extra Work Calculator — бесплатно

Откройтеindex.html после распаковки всей папки. Инструмент считает изменение ставки фиксированного проекта при дополнительных часах и отдельную цену этих работ. Аккаунт и сервер не нужны, данные не сохраняются и не отправляются.

## Получите результат за5минут

1. Выберите валюту: это метка, обменного курса здесь нет.
2. Введите фиксированный бюджет и базовые часы. Для уже идущего проекта используйте фактические часы до дополнительной работы; для планирования — оценку. Не смешивайте эти виды данных незаметно.
3. Укажите новые часы. Поле отдельной ставки необязательно: пустое использует бюджет / базовые часы.
4. Посмотрите снижение ставки, оценку доплаты и отдельный сценарий с доплатой.
5. СохранитеTXT или распечатайте расчёт для обсуждения. Это не счёт, договор или подтверждение оплаты.

## Полный пример

Пример вымышленный: проект12000₽ /12ч даёт1000₽/ч. Дополнительные6ч без доплаты увеличивают общее время до18ч, ставка получается666,67₽/ч, снижение33,33%. Оценка дополнительных6ч по1000₽/ч —6000₽. Если стороны согласовали эту доплату и включили её в бюджет, сценарий18000₽ /18ч снова даёт1000₽/ч. Сам расчёт не означает, что6000₽ уже оплачены.

Если указать ставку800₽/ч, предложенная доплата4800₽, общая сумма сценария16800₽, ставка933,33₽/ч. Такое значение может быть сознательным решением, а не ошибкой: приложение показывает арифметику.

## Что написать клиенту

«Запрос[описание] не входит в текущий объём. Оценка —[часы], доплата —[сумма], срок изменится на[срок]. До начала работы давайте письменно подтвердим новый результат и цену. Если остаёмся в исходном бюджете, предлагаю вместо этого убрать[часть объёма]».

Проверьте первоначальные договорённости: исправление собственного дефекта не следует автоматически продавать как новый объём. Калькулятор не принимает это решение за вас.

## Ограничения

Валовая арифметика без налогов, расходов, комиссий, округления счетов и конвертации валют. Нулевой бюджет допустим, нулевые базовые часы нет. Минусы и формулы не принимаются; десятичная запятая и пробелы в числах поддерживаются. Все выводы — сценарии на ваших входных данных.

Scope Change Desk добавляет исходный объём, журнал правок, запись согласования и документ для клиента. Ссылка ведёт прямо на страницу продукта Kornilov Tools.


## Карточка для пересылки

В блоке «Поделиться результатом» выберите «Копировать текст», «Скачать PNG» или «Скачать HTML». Одна галочка «Включить числа во все форматы» добавляет базовые и дополнительные часы, ставку после допработы и предложенную доплату. По умолчанию все эти числа скрыты во всех трёх форматах. Имена клиентов и проектов не включаются; демо явно помечается как вымышленное. После обновления расчёта или переключения языка галочка снова выключена. PNG создаётся локально средствами браузера и скачивается как изображение, а не копируется в буфер. Если копирование текста недоступно, появится выделяемое поле: скопируйте текст вручную через меню или Ctrl/Cmd+C. Текст и HTML содержат ссылку на бесплатный Extra Work Calculator для своего расчёта; в PNG адрес нарисован и не кликабелен. URL содержит только язык и общие UTM метки, без ваших данных. Сохранение файла запускается только по нажатию; проверьте его в загрузках. Приложение ничего не отправляет автоматически. Платное продолжение доступно из самого инструмента.
