# CSV Preflight — бесплатный инструмент Kornilov Tools

Проверьте CSV перед импортом: структура, дубли и пустые ID, ячейки, похожие на формулы. Инструмент **не меняет файлы**. Никаких аккаунтов, сервера или установки.

## Быстрый старт

Распакуйте всю папку и откройте **index.html** двойным щелчком в современном браузере. Нажмите «Проверить пример». Ожидается: 6 записей, 4 колонки, 1 повторяющийся ID в 2 записях, 1 пустой ID и 1 ячейка, похожая на формулу.

Затем выберите свой CSV/TSV, кодировку и разделитель. Укажите колонку с ID нужной сущности — заказа, товара, клиента. Посмотрите координаты проблем и первые 5/10/20 записей. Пошаговый сценарий: [GUIDE_RU.md](GUIDE_RU.md). English: [README_EN.md](README_EN.md).

## Что означает отчёт

- **Структура корректна**: заголовки уникальны и заполнены, кавычки закрыты, число полей одинаково. Это не подтверждение правильности бизнес-данных.
- **Повторяющиеся ID**: число уникальных значений, которые встречаются больше одного раза. «Записи с дублями» — все записи в этих группах.
- **Пустые ID**: пустая строка или только пробелы. Значения не исправляются.
- **Ячейки, похожие на формулы**: начинающиеся с `=`, `+`, `-`, `@` после пробелов, либо с некоторых управляющих символов. `-1` тоже отмечается: это предупреждение для ручной проверки, не диагноз вредоносности.
- Номер записи включает заголовок как запись 1. Перенос строки внутри кавычек не создаёт новую запись.

## Приватность

Файл читается в память страницы. Нет сети, аналитики, внешних библиотек, localStorage и сохранённых сессий. Ссылка на продукт открывает сайт только по вашему нажатию и не прикрепляет данные или отчёт. «Очистить» удаляет текущие ссылки на данные и предпросмотр; физической памятью управляет браузер.

JSON по умолчанию содержит **счётчики и координаты**, без значений ячеек, ID, заголовков и имени файла. Галочка «Включить значения ID в JSON» добавляет только ID групп дублей. Полный исходный CSV никогда не включается в JSON. Перед передачей отчёта проверьте эту галочку. Предпросмотр показывает локальные исходные значения, но не входит в экспорт.

При неправильной структуре счётчики неизвестны, предпросмотр скрывается, экспорт содержит `structureValid: false` и код ошибки. До 200 координат формул включаются в JSON с явным числом пропущенных; полный счётчик точный. Все группы дублей и номера пустых ID включаются в отчёт.

## Пределы

До **2 МиБ (2 097 152 байта), 10 000 записей, 100 колонок** на файл. UTF-8/BOM или явно выбранная Windows-1251; запятая, `;`, Tab. Нет XLSX, автоисправления, нормализации, нечётких совпадений и сверки двух файлов. `001`, `1`, `A` и ` a ` — разные ID. Для единственной колонки и неоднозначного CSV выберите разделитель вручную. Пустые многоколоночные строки и пробелы после закрывающей кавычки вызывают строгую ошибку.

Бесплатные рабочие файлы можно распространять с указанием Kornilov Tools, но не перепродавать. [LICENSE.txt](LICENSE.txt). Каталог: [Kornilov Tools](https://pease163.github.io/digital-products/).


## Карточка для пересылки

В блоке «Поделиться результатом» выберите «Копировать текст», «Скачать PNG» или «Скачать HTML». Одна галочка «Включить счётчики во все форматы» добавляет количества записей, повторяющихся и пустых ID, ячеек, похожих на формулы. По умолчанию все счётчики скрыты во всех трёх форматах. Имена файлов, заголовки, ID, значения ячеек и координаты записей никогда не включаются. Галочка ID для полного JSON не влияет на эти форматы. Демо явно помечается как вымышленное. При обновлении отчёта или переключении языка раскрытие счётчиков снова выключено; при ошибке структуры счётчики недоступны. PNG создаётся локально средствами браузера и скачивается как изображение, а не копируется в буфер. Если копирование текста недоступно, появится выделяемое поле: скопируйте текст вручную через меню или Ctrl/Cmd+C. Текст и HTML содержат ссылку на бесплатный CSV Preflight для проверки своего файла; в PNG адрес нарисован и не кликабелен. URL содержит только язык и общие UTM метки, без ваших данных. Сохранение файла запускается только по нажатию; проверьте его в загрузках. Приложение ничего не отправляет автоматически. Платное продолжение доступно из самого инструмента.
