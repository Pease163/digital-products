Отчёт о качестве

По умолчанию JSON содержит только счётчики и номера записей/колонок. Значения ячеек и имена файлов не экспортируются. Галочка добавляет только повторяющиеся ID.

Проверка ничего не меняет. Повторяющиеся ID сравниваются точно: 001 и 1 различаются, пробелы и регистр сохраняются.
