Минута 1: посмотрите знакомый пример

Откройте index.html и нажмите «Проверить пример». Это demo.csv: небольшая складская выгрузка, где ID 002 повторяется, у одной записи ID отсутствует, а заметка содержит =1+1. Кавычки и многострочное описание при этом корректны.

Итог: 6 записей, 4 колонки; 1 группа дублей / 2 записи; 1 пустой ID; 1 формула-похожая ячейка. У корректного CSV тоже могут быть проблемы качества.

Минута 2: проверьте собственный файл

Выберите CSV/TSV через поле файла. Укажите UTF-8 или Windows-1251 по настройкам экспортирующей программы. Выберите разделитель — авто, запятую, точку с запятой или Tab. Если авто сомневается, оно не угадывает: выберите явно.

Если есть структурная ошибка, видны сообщение и неизвестные счётчики «—», а предпросмотр отсутствует. Проверьте кавычки, пустые строки и число полей. Не принимайте отчёт об ошибке за успешную проверку.

Минута 3: выберите правильный ID

Выберите SKU для товаров или Order ID для заказов. Имя покупателя может повторяться законно и обычно не подходит для ключа заказа. Посмотрите, как меняются группы дублей при выборе другой колонки.

В примере дубль 002 расположен в записях 3 и 4, пустой ID — в записи 5, формула-похожая заметка — запись 6, колонка 4. Заголовок — запись 1. Предпросмотр первых 5/10/20 строк помогает найти эти записи.

Минута 4: решите, что исправить в источнике

Дубль может быть ошибкой экспорта или законной повторяющейся строкой: инструмент этого не решает. Уточните, должна ли выбранная колонка быть уникальной. Пустой ID нужно заполнить в исходной системе. Формула-похожую заметку проверьте перед открытием в Excel; даже отрицательное число будет отмечено.

Ни одна строка не удаляется, первая из дублей не выбирается, ID не обрезаются и числа не преобразуются. Исправьте источник, выгрузите заново и повторите проверку.

Минута 5: сохраните безопасный по содержимому отчёт

Оставьте «Включить значения ID в JSON» выключенной и нажмите JSON ↓. Получите счётчики, группы с номерами записей, пустые ID по номерам и координаты формул — без исходных значений или имени файла. JSON удобен для передачи коллеге с инструкцией, где проверить источник.

Если коллега имеет право видеть ID, галочка добавит ID повторяющихся групп. Остальные ячейки всё равно не экспортируются. Для примера без галочки результат соответствует expected-report.json по счётчикам и координатам; интерфейс дополнительно указывает параметры входного файла.

Условия: до 2 МиБ / 10 000 записей / 100 колонок. Инструмент не подтверждает правильность цен, статусов и данных людей и не является антивирусом. После работы нажмите «Очистить». Каталог других решений Kornilov Tools доступен через кнопку Boosty; переход добровольный, данные не передаются.

Карточка для пересылки

Скачайте автономную карточку HTML. По умолчанию она показывает только итог проверки; счётчики включаются отдельной галочкой. В неё никогда не входят имя файла, заголовки, ID, значения ячеек или координаты записей. Галочка ID для полного JSON не влияет на карточку. Карточка создаётся локально и не отправляется автоматически. CTA открывает страницу CSV Reconcile Desk; ссылка содержит только общие UTM метки, без ваших данных.
