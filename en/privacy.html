Data and privacy

Free tools process files and calculations in your browser. We do not ask you to send your source data to the creator.

Work data

CSV files are processed in browser memory. Local editors may save workspaces in your browser storage; this is not a backup or cloud sync. Download JSON copies and review outputs before sharing them.

Website and links

The site is hosted on GitHub Pages. Purchases and messages use Boosty, and updates use Telegram; those services have their own data policies. External links may contain UTM parameters for the tool and link placement. These never include files or calculation values.

Usage events

Central event collection is disabled on this site. Action names are kept only in the current tab’s memory and disappear when it closes. Text, file names, calculation values and CSV contents are never included in events.
